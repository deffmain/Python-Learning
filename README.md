# 🐍 Python Learning

Anotações e exercícios da minha jornada de aprendizado em Python.

## 📁 Estrutura

- `Python - Basics/` → o que é Python e usos comuns, variáveis e convenções de nomenclatura, comentários, `print()`, tipos de dados, strings e seus métodos, inteiros e floats, atribuição aumentada, condicionais, truthy/falsy, operadores booleanos, funções (embutidas e personalizadas, parâmetros, argumentos, `return` e `None`) e escopo local e global + exercícios práticos (strings, cálculo de uma conta, reserva de ingresso e planejador de viagem com condicionais, estoque de cozinha com funções e escopo)

## 🎯 Objetivo

Consolidar os fundamentos de Python com anotações revisadas e exercícios práticos.
